---
title: "Sources"
description: "Postgres tables, files in S3 or a folder, and Python sources: the three kinds of source and the settings they share."
---

A source is where data comes from. SQLLoad has three kinds:

| `kind` | Reads | Tables | Declared in |
|--------|-------|--------|-------------|
| [`postgres`](/docs/sources/postgres/) | Tables of a Postgres database, with binary `COPY` | One per matching source table | `sqlload.toml` |
| [`files`](/docs/sources/files/) | Parquet, CSV, JSON or NDJSON files in S3 or a local folder | One per source | `sqlload.toml` |
| [Python](/docs/sources/python/) | Whatever a Python function yields: dicts, Arrow data, JSON bytes, HTTP jobs | One per decorated function | Python, under `python_paths` |

Every source loads into a target: its `destination`, or the project's `default_target`. Settings
that shape tables (`write_strategy`, `unique_key`, `cursor_column` and the rest) can be set on the
source as defaults for all its tables, and per table. See
[`sqlload.toml`](/docs/configuration/#table-settings) for the full list.

Each kind has its own page:

- [Postgres](/docs/sources/postgres/): choosing tables and columns, masking, and how tables are read.
- [Files](/docs/sources/files/): formats, partitions, which files load, and files the destination
  reads itself.
- [Python](/docs/sources/python/): any API, SaaS or custom source as a table, including REST APIs
  that run entirely in Rust.
