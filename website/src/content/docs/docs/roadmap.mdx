None of this is in a release yet, and there are no dates. Everything else on this site documents
what SQLLoad ships today; see [Supported systems](/docs/supported-systems/).

## More for BigQuery

[BigQuery](/docs/targets/bigquery/) targets are in preview. Not yet: records as typed `STRUCT`
columns (they load as `JSON`), `array(timestamp_tz)`, and the
[Postgres CDC](/docs/sources/postgres-cdc/) source into BigQuery.

## Database to database

Eventually, warehouses and databases as sources, with SQL translated between their dialects.
Translation will cover only what can be expressed equivalently in DuckDB, which serves as the
common dialect. SQLLoad deliberately won't build a matrix of every dialect into every other, which
no reasonable budget could test. The aim is fewer routes, each one checked, over more routes that
aren't.
